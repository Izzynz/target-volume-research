Privacy Policy

Target Volume Research — effective 31 August 2026 — last updated 31 August 2026

Overview

Target Volume Research ("the app") is a single-user internal tool operated by Hugsy Limited ("we", "us"). The app reads keyword search-volume metrics and related search terms from the Pinterest API to help prioritise which marketing topics to create content for. The app is not offered to the public and has no end users other than its operator.

What the app accesses via the Pinterest API

  • Keyword search-volume metrics (aggregated, anonymised search frequency buckets).
  • Related search terms for input keywords.
  • Basic account information required by the OAuth authorisation flow.

The app does not publish Pins, create or modify boards, run advertising campaigns, or read any Pinterest user's personal content, messages, or profile data.

Data we collect

We do not collect, store, or process any personal data about Pinterest users or any other individuals. The only data the app stores is:

  • An OAuth access token for the operator's own Pinterest account, stored locally on the operator's machine and used solely to authenticate API requests.
  • Aggregated, anonymised keyword metrics returned by the Pinterest API (for example, search-volume ranges such as "100K–500K").

How data is used

Keyword metrics and related terms are used solely for internal marketing research: deciding which content topics are worth pursuing. No data is used for advertising to individuals, profiling, or automated decision-making about people.

Sharing and disclosure

We do not sell, rent, share, or disclose any data obtained through the Pinterest API to any third party. Data remains on the operator's own infrastructure.

Data retention and deletion

Aggregated keyword metrics are retained for internal reference. The OAuth token can be revoked at any time from the Pinterest account settings, which immediately ends the app's access. On revocation or uninstall, all locally stored credentials are deleted.

Security

API credentials are stored in a local, non-committed environment file with filesystem-level access controls. All API traffic uses HTTPS.
